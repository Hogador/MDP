### F-108 [CRITICAL] P-256 Precompile (RIP-7212) — НЕДОСТУПЕН на BSC — требуется FCL

| Field | Value |
|-------|-------|
| **ID** | F-108 |
| **Severity** | CRITICAL |
| **Category** | C5 (precompile) |
| **Bug pattern** | `rip7212-unavailable` |
| **Fingerprint** | `sha256("C5:SocialRecoveryModule.sol:P256_VERIFIER:rip7212-unavailable")` → `f108...` |
| **Status** | REGRESSED |
| **Found** | BSC Testnet Audit 2026-06-29 |
| **Regressed** | 2026-07-01 — on-chain проверка подтвердила: RIP-7212 (0x100) не существует на BSC Mainnet и Testnet. Staticcall возвращает `(true, 0x0)`. `_verifyWebAuthn` всегда false. |

**Description:** SocialRecoveryModule использует P-256 precompile at 0x100 (RIP-7212), который НЕ АКТИВЕН на BSC Testnet и Mainnet. `staticcall` к несуществующему precompile возвращает `(true, 0x00)` — recovery невозможен.

**Impact:** CRITICAL — блокер для testnet. Весь social recovery на BSC неработоспособен.

**Required fix:** 
1. pure-Solidity P-256 verifier на базе FCL (Fresh CryptoLib) — не MockP256 (возвращает 1 для любого input, ломает security)
2. `FCLP256Verifier.sol` — обёртка над FCL.p256Verify()
3. Задеплоить, вызвать `setP256Verifier(address(fclVerifier))`
