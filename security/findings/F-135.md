### F-135 [CRITICAL] SIWE auth отсутствует — Web3 gasless flow недоступен

| Field | Value |
|-------|-------|
| **ID** | F-135 |
| **Severity** | CRITICAL |
| **Category** | A1 (auth) |
| **Bug pattern** | `siwe-auth-missing` |
| **Fingerprint** | `sha256("A1:relay:auth:siwe-missing")` → `f135...` |
| **Status** | NEW |
| **Found** | External Audit Wave 15 (2026-07-01) |

**Description:**
`AuthService.kt` — только `register(email,password)` и `login(email,password)`. `/v1/sign` требует JWT (`Application.kt:232`). Web3-native пользователи без email не могут использовать gasless flow. SIWE (EIP-4361: Sign-In with Ethereum) не реализован.

**Impact:** CRITICAL — весь gasless payment flow недоступен для Web3-кошельков.

**Required fix:**
1. POST `/v1/auth/siwe` на relay — принимает `{ message: EIP-4361 string, signature: hex }`
2. Валидирует message (domain, nonce, issuedAt)
3. ecrecover → address → проверяет в OnChainRegistry (или разрешает без регистрации)
4. Выдаёт JWT с `sub=address`, `method=siwe`
5. Обновить Application.kt middleware — пропускать `sub=address` через SIWE JWT
