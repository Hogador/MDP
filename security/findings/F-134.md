### F-134 [CRITICAL] GCP KMS не поддерживает secp256k1 (аннулирует F-129)

| Field | Value |
|-------|-------|
| **ID** | F-134 |
| **Severity** | CRITICAL |
| **Category** | D1 (secrets) |
| **Bug pattern** | `kms-wrong-curve` |
| **Fingerprint** | `sha256("D1:backend:kms:gcp-no-secp256k1")` → `f134...` |
| **Status** | NEW |
| **Found** | External Audit Wave 15 (2026-07-01) |

**Description:**
GCP Cloud KMS поддерживает только `EC_SIGN_P256_SHA256` (secp256r1/P-256) и `EC_SIGN_P384_SHA384`. Ethereum использует secp256k1. GCP KMS **физически не может** подписывать Ethereum-транзакции.

**Impact:** CRITICAL — F-129 (KMS) не может быть реализован на GCP.

**Required fix:**
AWS KMS с `ECC_SECG_P256K1` (поддерживает secp256k1). Альтернативы: HashiCorp Vault, DKMS (DIY),或者在 локальном HSM.

**Cross-ref:** F-129 (необходимо переписать).
