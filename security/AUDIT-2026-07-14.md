## 🔴 CRITICAL (5)

### SA-001 — Wallet mnemonic decryption silently fails on Android 11+
- **File:** `KeystoreCrypto.kt:98-114`, `WalletManager.kt:50-56`
- **Issue:** `decrypt()` catches `InvalidKeyException` and returns null. After 300s auth window, `loadWallet()` always fails. Wallet permanently inaccessible.
- **Fix:** Trigger BiometricPrompt with CryptoObject before decrypt.

### RA-001 — Replay attack on all authenticated endpoints (no nonce)
- **File:** `relay/src/auth.ts:90`
- **Issue:** HMAC `"${timestamp}.${body}"` without nonce. Replayable within 5min window.
- **Fix:** Add nonce to HMAC: `"${timestamp}.${nonce}.${body}"`, store spent nonces in KV.

### RA-002 — SIWE has no nonce, expiry, domain, or chainId validation
- **File:** `relay/src/siwe.ts:28-39`
- **Issue:** Only checks signature recovery. Accepts phishing-signed SIWE messages.
- **Fix:** Parse SIWE fields, validate nonce/exp/domain/chainId.

### RA-003 — JWT has no expiration
- **File:** `relay/src/siwe.ts:16-25`
- **Issue:** `{ sub, method, iat }` — no `exp` claim. Token is eternal.
- **Fix:** Add `exp: iat + 3600`.

### RA-004 — No CORS / no security headers
- **File:** `relay/src/index.ts:67-77`
- **Issue:** No `Access-Control-Allow-Origin`, no `Cache-Control`, no security headers.
- **Fix:** Add CORS for `app.mdaopay.com`, `Cache-Control: no-store`, etc.
